# coco

一个只在自己工作区里干活的视觉 agent。窗口左边是 coco，右边是它的工作区：网页、桌面应用和 WSA 安卓应用以拼贴的方式排在 coco 窗口里。coco 靠截图看这些拼贴，用鼠标和键盘操作它们完成任务，看不到也碰不到工作区以外的东西。

Electron + React + TypeScript，Windows 10/11。给使用者看的完整说明（含 WSA 安装）见 [coco使用说明.md](coco使用说明.md)。

## 启动

需要 Node.js 22.12+（推荐 24 LTS）。

```powershell
npm install
npm run dev
```

也可以双击 `启动coco.cmd`：优先打开 `release/v0.5.0/win-unpacked/coco.exe`，其次尝试旧版包，否则安装依赖、构建并启动。

## 使用

- **工作区**：标题栏上的标签。每个工作区有自己的 coco 和自己的拼贴，可以多开、同时工作。双击标签改名，`Ctrl+Shift+N` 新建。
- **Agent 分身**：左侧标题栏可向右 / 向下拆分，最多 12 个；支持最大化、还原、关闭和拖动缝隙调整尺寸。各分身拥有独立对话、草稿、任务计划、等待、重连和暂停 / 停止控制。关闭分身会停止它的任务并保留右侧应用。分身共享所在工作区的拼贴和文件夹，模型设置全局共用；可以按 A、B 等拼贴编号分配不同任务。切换工作区或设置页会保留分身布局和草稿，退出客户端后不会恢复分身。
- **拼贴**：空拼贴里可以打开网页、开始菜单里的应用、WSA 安卓应用，或接入一个已经打开的窗口。拼贴按列排布、列内上下堆叠：标题栏按钮向右 / 向下拆分、最大化、关闭，拖动缝隙调整大小，`Ctrl+Shift+T` 新建拼贴。
- **嵌入的应用**跟随 coco 移动、缩放和最小化，被拖出拼贴或最大化会自动弹回，切换工作区时隐藏。普通应用去掉标题栏；WSA 保留原生标题栏，避免安卓内容顶部被透明的窗口按钮区域拦截。关闭拼贴会关闭其中的应用；退出 coco 时窗口会带着原来的标题栏和位置还给桌面。
- **本地文件夹**：每个工作区可以在左栏顶部绑定一个文件夹（按工作区名记住）。coco 会多一个 `folder` 工具：列出、查找、读取（UTF-8 / GBK）里面的文件，把文件打开进拼贴，在里面新建文件，再按文件内容操作拼贴。拼贴启动器的「文件」页也能手动打开。
- **和 coco 对话**：说清要做什么。它工作时可以暂停，你直接在拼贴里动手后再继续；遇到需要你决定的事它会提问。同一分身里的后续消息会接着上文；`Ctrl+K` 聚焦当前分身的输入框。
- **任务计划**：开始时先列步骤，左栏显示待进行、进行中和已完成，并随执行更新。
- **长等待**：视频播放、下载等耗时过程可以每分钟截图一次，间隔内不调用模型；设置里可以调整默认间隔，任务中也可指定。左栏显示倒计时，暂停会冻结等待，停止会取消等待。
- **自动重连**：连接中断、超时或临时服务错误时，保留当前计划和已执行记录，只重试模型请求。默认最多重试 6 次，间隔从 2 秒逐步增加；耗尽后暂停，点击“继续”在原任务上重试。密钥、权限、余额等错误会直接提示。

## coco 的视野

- 工作区工具有 `tiles`（列出 / 打开 / 关闭拼贴）、`look`（截图）、`act`（点击、拖动、滚动、输入、按键、短等待）、`web`（网页拼贴的导航、读取页面和按编号点击 / 填写）。引擎还提供 `update_plan`（维护计划）、`wait`（长等待后截图一次，10–3600 秒，默认 60 秒）、`request_user_input`（提问）。绑定了文件夹时多一个 `folder`。没有桌面截图或终端工具。
- `folder` 只在绑定的文件夹里：路径解析时跟随符号链接和 junction，出了文件夹就拒绝；已有文件只读，只能新建文件或改自己这次新建的；只能打开文档、图片和音视频，程序和脚本一律不打开；从文件夹打开的网页只能链接到文件夹里的文件。
- 截图只截拼贴本身：网页用 `capturePage`，应用用 `PrintWindow`。只有当画面确实属于该窗口时才退回屏幕取像，被别的窗口挡住就拒绝。每次操作后自动附上新截图，coco 以看到的画面为准。
- 点击、按键和网页导航后默认在本地等待 2 秒再截图；`act` / `web` 的 `wait_after` 可指定 0.3–15 秒，适合加载较慢的页面。等待期间没有中间截图或模型请求，只返回最后一张截图；停止任务会中断等待。
- 坐标是拼贴截图内 0–1000 的归一化坐标；点击前检查该点确实属于目标窗口。
- 网页拼贴的输入直接送进页面，后台工作区也能操作；桌面和安卓应用用真实鼠标键盘，操作前会把所属工作区切到前台，多个工作区的这类操作排队进行。文字用逐字 Unicode 按键输入，中文同样适用（WSA 安卓应用已验证）。

## 配置模型

在「设置」里填写 API 地址（例如 `https://api.openai.com/v1`，自动请求 `/responses`）、API Key 和模型 ID。模型需支持 Responses API、图片输入和函数工具调用。先「测试连接」再「测试视觉」，然后保存。

Key 用 Electron `safeStorage`（Windows 系统加密）保存，界面读不到已保存的 Key。拼贴截图和任务会发送给你配置的模型服务；视觉测试只截取 coco 自己的窗口。任务记录保存在用户数据目录，截图只留在当前会话里。网页下载保存在「下载/coco」。

## 目录

```text
electron/
  main.cjs             窗口、IPC、退出时归还嵌入窗口
  workspaces.cjs       工作区与拼贴：网页视图、应用接管与位置跟随、截图、输入
  folder.cjs           工作区文件夹：路径框定、列出 / 查找 / 读取 / 新建、可打开的文件类型
  native.cjs           常驻 PowerShell 窗口服务的客户端
  native/host.ps1      Win32：窗口枚举、去边框与所有者、定位、PrintWindow、鼠标键盘、开始菜单与 WSA 应用
  tools.cjs            agent 可用的工具，全部限定在所属工作区
  agent.cjs            对话循环、暂停 / 接管 / 提问、上下文与截图裁剪
  provider.cjs         Responses API 适配
  config.cjs           设置校验与密钥加密
  history.cjs          任务记录
src/
  App.tsx              标题栏工作区标签、左右分栏、布局同步
  layout.ts            列 + 堆叠的拼贴布局（纯函数）
  components/          AgentPanel、TileArea、Launcher、设置与历史
scripts/               开发启动、冒烟测试、原生嵌入验证、图标生成
tests/                 引擎、服务、布局的单元测试
```

## 测试

```powershell
npm test              # 引擎、服务、布局、窗口服务协议、延迟截图与取消
npm run test:agents   # 本地模拟模型：分身布局、独立上下文、并发任务与关闭隔离
npm run test:smoke    # 用本地模拟模型跑完整流程：网页拼贴 + 嵌入记事本
npm run test:native   # 嵌入窗口跟随移动 / 缩放、随工作区隐藏、退出时归还
npm run test:native-input # 原生焦点、首击时序、跨进程裁剪截图与点击坐标回归
npm run test:folder   # 绑定文件夹：读任务文件、打开进拼贴、新建结果，越界和程序被拒绝
npm run test:planning # 本地模拟模型：计划、分钟等待、自动重连与历史记录
npm run test:dev      # 开发服务器与预加载
npm run build         # 类型检查与界面构建
npm run dist:dir      # 生成免安装目录 release/win-unpacked
npm run dist          # 生成 NSIS 安装包
npm run icon          # 重新生成 build/icon.png 与 icon.ico
```

## 已知限制

- 自动重连只恢复仍在运行的客户端中的任务；退出或重启客户端后，未完成任务会标为中断，需要重新发起。长等待每次观察仍会调用模型并计入轮次，较长任务可提高轮次上限。
- 嵌入用的是「coco 窗口作为所有者 + 位置跟随」，不是 `SetParent`；普通应用另做去边框处理。WSA 保留原生边框和标题栏；部分 UWP 也可能显示自绘标题区域。
- 以管理员权限运行的应用无法接管或操作。
- 单实例桌面应用已经在运行时，启动不会出现新窗口，需要在「窗口」里接入；安卓应用已在运行时会按包名直接找到。
- WSA 已由微软停止支持，需要本机已安装 WSA；首次启动较慢。
- 后台工作区里的桌面 / 安卓应用要切到前台才能看和操作；网页拼贴不受影响。
